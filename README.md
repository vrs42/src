# src

This is a module repo which supports www.so-much-stuff.com.

It includes images and documentation for various pieces of
PDP-8 software, including software sold by DEC, software
distributed by DECUS, and various other software for the
PDP-8 and PDP-12 computers.

## Requirements

The files are typically paper tape (or other media) images in
file formats relevant to the PDP-8.  You may want the tools
and documentation from the "8tools" module to make best use
of them.

## Installation

* git clone https://github.com/vrs42/src.git

Note that this will check out the files, and some PDF documents,
but not the index files, which are built by the code in the "trunk"a
repo.
