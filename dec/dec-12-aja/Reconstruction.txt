The "roundup" script creates a set of unique candidates for analysis from the
existing DIAL images.

There are three distinct binaries of Focal12 for DIAL:
57236.bd	Probably the oldest. Has assembler support for the dialog, but
		not the Focal part.
16383.bd	Slightly newer looking.
55370.bd	This version matches the listing, dec-12-ajaa-la.pdf.

Note that dec-12-ajaa-d.pdf actually describes a slightly different version
than any of the above. The file "writeup.syms" is thus slightly different
from "listing.syms".

For each of these three binaries, 'bd2bin' has been run to create a
corresponding file iwth extension ".ok".

For 55370, the disassembly was matched to the PDF listing file by hand.

Then, for 16383 and 57236, that source was further manipulated to match
the respective binary.

The Makefile has the steps to remake .bin files from the .pal, then compare
them to the .ok files.  (Listings are generated with symbol tables.)

In an effort to provide an obvious download choice, "12-ajaa" is maintained
as an alias for "55370".
