This is the build directory from dec-08-lfcla, with quad8i.pa edited to
set DVCE=1.  This causes dec-08-aj7e-pb to be built instead of dec-08-aj8e-pb.

Naming Conventions:
%	Original Source File
%.bn	Original Binary File, if any

%.pa	Converted to 7 bit ASCII, trailing ^Z removed, newline issues addressed
%.pal	Concatenated for assembly, if needed
%.bin	Output from cross assembly
%.lst	Output from cross assembly
