MAINDEC-8E-D1JB-D-(D)

MR8-EA READ ONLY MEMORY TEST

ABSTRACT
	THE READ ONLY MEMORY TEST IS A PROGRAM TO COMPARE A WIRED MEMORY
	TO A BINARY TAPE. THE BINARY TAPE IS PROVIDED BY THE CUSTOMER.
	THROUGHOUT THIS URITE UP AND MESSAOE TYPEDUTS, THE DIAGNQSTIC
	WILL BE REFERRED TO AS (ROM TEST TAPE). THE BINARY TAPE THAT
	IS PROVEDED BY THE CUSTOMER WILL BE REFERRED TO AS (ROM CONTENTS TAPE).
	THIS ROM CONTENTS TAPE MAY ALSO BE SUPPLIED BY DIGITAL EOUIPMENT INC.
	AS ROM TD8E SYSTEMS HANDLER (MR8-EC) WITCH WILL CONSIST OF A
	LISTING AND A PAPER TAPE (8E-D1KA-PB).
	THE RON TEST TAPE MAY BE LOADED AND RUN IN ANY FIELD.
	THE ROM TEST TAPE NILL COMPARE THE RON CONTENTS TAPE AND THE
	ROM IN THREE WAYS. TEST 1 IS A DIRECT COMPARISON OR THE TWO.
	THE SECOND TEST IS A RANDOM ACCESS DATA COMPARE, AND
	THE THIRD TEST IS A VARIABLE DELAY WITH RANDOM ACCESS.
	IN EACH OF THE THREE TESTS ALL 400 LOCATIONS WILL BE EXAMINED.

REQUIREMENTS
	PDP-8/E WITH 4K MEMORY AND 2 PAGE MR8-EA ROM. LOW SPEED OR HIGH
	SPEED READER AND ASR 33 TELETYPE OR EOUIVALENT:

STORAGE
	ROM TEST TAPE LOW (MAINDEC-8E-D1JA-PB1) WILL OCCUPY 0-4000. ROM TEST
	TAPE HIGH (MAINDEC 8E-D1JA-PB2) HILL OCCUPY 4600-7700. THE ROM ITSELF
	MAY OCCUPY 400 LOCATIONS IN ANY FIELD.

LOADING
	CHECK AOQRESS OF ROM AND THE ROM TEST TAPE TO SEE THAT THEY DO
	NOT OVERLAY EACH OTHER IN CORE.

	USING BINARY LOADER, LOAO IN ROM TEST TAPE LOW OR ROM TEST
	TAPE HIGH DEPENDING ON WHERE ROM IS LOCATED.

STARTING PROCEOURE
	SET SWITCH REGISTER TO 0400 OR 5200
	PRESS LOAD ADDRESS, CLEAR AND CONTINUE
	SET SWITCH 0 FOR HIGH OR LOW SPEED READER AND PLACE (ROM CONTENTS
	TAPE) IN READER
	"PRESS CQNTINUE"
	SET SWITCH REGISTER FOR ROM START ADDRESS AND FIELD
	"PRESS CONTINUE"
	SET SWITCH REGISTER FOR DESIRED FUNCTIONS
	"PRESS CONTINUE"

PRINTOUTS - YES

SWITCH REGISTER OPTIONS - YES
	SW0 = 1 LOOP ON ERROR
	SW1 = 1 NO ERROR PRINT OUT WILL OCCUR
	SW2 = 1 INHIBIT ERROR HALTS
	SW6-8 = EXECUTION OF TEST 1, 2, 3
	SW6 = 1 TEST ONE WILL BE PERFORMED
	SW7 = 1 TEST TWO WILL BE PERFORMED
	SW8 = 1 TEST THREE WILL BE PERFORMED
	SW11 =1 CONTINUOUS LOOPINC THROUGH THE SELECTED TESTS

	IF SWITCHES 6,7,8 ARE NOT SET ALL TESTS WILL BE PERFORMED.
