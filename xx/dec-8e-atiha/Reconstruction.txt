Once again, the binary and source don't quite agree, so I've gone with the
binary.

The binary stores in location 0000, so beware.  The source copy uses an
on-page temporary instead.  The source doesn't compile correctly with the
cross assembler, however.  The line
	*.-1 177+1
does not get you to the next page; it assembles as if you'd written
	*.-1;177+1
There are also a versional differences at 01150 and 01336.

dec-8e-apsta/pstd1 and dec-8e-atiha/tihd2 are quite similar.
