CALCO 12
12-42
Author: Richard Reeder, State University of New York, Stony Brook, New York
This plotter program can be used with programs like CATACAL to obtain reasonably high-speed hard copy of data which is stored on tape.
Minimum Hardware: PDP-12, Model 565 CalComp Plotter, VR12 Display, One LINCtape Unit, EAE
Storage Requirement: 1K of core
Source Language: DIAL
Catalog: July 1974
