3 Dimensional TIC TAC TOE (3X3X3)
FOCAL8-99

Leonard Fertuck, Saskatoon Research Council, Saskatoon,
Saskatchewan, Canada

This program plays a game of 3 dimensional Tic Tac Toe in
which the object is to maximize the total number of lines
when all eel Is in the 3X3X3 cube have been filled. Game
rules and operating instructions are provided as comments in
this program.

Minimum Hardware:
4K PDP-8
Source Language:
FOCAL-69

Catalog: July 1973
