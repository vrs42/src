Bar Chart Plotting Subroutine
8-279

G. L. Kermez and W. G. Peters, Texas Instruments Limited,
Bedford, England

This program was written as part of the main operating pro-
gram of a power transistor test system produced by the authors.
The chart requires 7 constants for its construction. The table
can be as large as required. Many charts can be plotted from
one table because the table is not altered in any way by the
subroutine. This allows the drawing of a family of charts of
one set of readings for different classes and numbers.

Minimum Hardware:
4K PDP-8/L, ASR-33
Source Language:
MACRO-8

Catalog: July 1973
