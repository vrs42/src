Keyboard Controlled Binary Punch
8-187

Edward A. Taft III, St. Mark's School, Southboro, Mass-
achusetts

This program makes binary tape copies of selected areas of
core. It is entirely keyboard controlled, and has provisions
for punching leader, data, checksums and field marks for
extended memory programming.

Minimum Hardware:
PDP-8, High-Speed Punch
and Extended Memory (optional)

Source Language:
PAL-D

Storage Requirement:
1 page (versions included
occupy 1, 36 and 37).

Catalog: November 1969
