FOCAL-12 Overlay to Access the DF 32 Disk
12-176
Author: University Observatory, Vienna, Austria
Access is provided to the DF 32 disk from FOCAL-12 via the FZ user function. There are two files: a 2K integer file and a 1K floating point file.

The programs are offered on DIAL-readable paper tape (source).

Minimum Hardware: PDP-12, DF32 random access disk
Other Programs Needed: FOCAL-12
Storage Requirement: 8K
Source Language: DIAL
Catalog: December 1974
