BOSS
8-200

Dr. A. S. French,
Submitted by: Dr. R. B. Stein, University of Alberta,
Edmonton, Alberta, Canada

BOSS allows a series of system programs to be brought into
core and executed in either one or any number of runs without
keyboard input, other than the initial listing of programs
and a single decision input at the end of each run.

Minimum Hardware:
PDP-8 with DF32 or DECtape

Source Language:
PAL III

Other Programs Needed:
Disk Monitor System
(DEC-08-SDAA)

Storage Requirement:
Disk - 2 blocks
DECtape - 3 blocks

Restriction:
File name must begin with
a letter.

Catalog:November 1969
