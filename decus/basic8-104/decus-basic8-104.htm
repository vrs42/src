QCHESS: Quigley's Algebraic Chess Program
BASIC8-104
Author: Edward John Quigley, Levittown, NY
Source Language: BASIC
Abstract: QCHESS is a Chess game written in BASIC that uses an algorithmic model of the game of Chess. The program as submitted to DECUS represents the end of about two years of work. Originally written for the PDP-8, QCHESS has been run on several different computers.
