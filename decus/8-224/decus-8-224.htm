PALT: Patch for Improved Text Handling for PAL-D
8-224

Frank Battat, Liberty Gold Fruit Co., Inc., San Francisco,
California

This patch eliminates the use of stripped ASCII code For
packing, instead the logic subtracts the number 2378 from
each ASCII code. This allows ASCII codes 2408 through 3368
to be packed two per word but allows for a more efficient
unpacking routine.

Minimum Hardware:
PDP-8 with Disk or DECtape

Other Programs Needed:
PAL-D (DEC-D8-ASAB-PB)

Source Language:
PAL-D

Catalog: July 1973
