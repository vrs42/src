PEST/WALD/PINIT: Adaptive Psychophysics Testing Package
8-520

H, L. Kaplan, M. M. Taylor, C. D, Creelman, University
of Toronto, Toronto, Canada

Three subroutines to run adaptive psychophysical testing using
procedures developed by M. M. Taylor and C. D. Creelman
(PEST: Efficien1 Estimates On Psychophysical Functions,
Journal of the Acoustical Society of America, 1967, 41,
782-787) for rapid location of "threshold" stimulus values.
Included is an extensive demonstration and testing package
and some examples of using PEST.

Minimum Hardware:
4K PDP-8, TTY
Storage Requirement:
2008 for main subroutines; 10008
for demonstration packages
Source Language:
PAL III

Catalog: July 1973
