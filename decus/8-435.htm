This is a program to read or write 32K words between disk and
DECtape. This utility provides for saving a disk image on
DECtape, restoring the disk from an image on tape and verifying
a disk image against a DECtape. It is a disk to-and-from
DECtape program.

Minimum Hardware:
8K PDP-8/I, DF32 disk, 1 DECtape
Storage Requirement:
0-1577 field 0
Source Language:
MACRO-8, PAL-8

Catalog:February 1972
