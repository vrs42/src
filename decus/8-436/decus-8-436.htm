EAE - Simulator
8-436

Tuan YoDinh and Urs P. Wild, Physical Chemistry Laboratory,
Federal Institute of Technology, Zurich, Switzerland

This software simulates all the Extended Arithmetic Element
(EAE) hardware instructions and allows the user to run any
program which was originally written for a PDP-8/I having the
EAE option on a PDP-8/I without it. All EAE instructions
have to be replaced by corresponding JMS instructions.

Minimum Hardware:
PDP-8/I
Storage Requirement:
208 locations on page 0 plus
2 pages
Source Language:
PAL III

Catalog:February 1972
