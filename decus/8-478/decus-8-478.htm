Monitor Command Extensions in PS/8
8-478

John R. Covert, Georgia Institute of Technology, Atlanta,
Georgia

This package expands the monitor ('.' mode) command set. It
adds LOGON, KJOB, CREATE, EDIT, COMPILE, DELETE,
RENAME, DIRECT and FILE commands in PDP-10 compatible
syntax.

See also DECUS NOS. 8-334, 8-473 and 8-476.

Minimum Hardware:
PS/8 configuration
Other Programs Needed:
PS/8 software
Restrictions:
Uses slightly more disk than
6 Nov. 70 release of PS/8;
some monitor level operations
will be slower for DECtape only
configuration.
Source Language:
PAL-8, FORTRAN

Catalog: July 1973
