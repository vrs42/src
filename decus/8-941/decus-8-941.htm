Abstract: OS/78 is a software system designed to support the VT278,
DECstation 78, and DECstation 88 computer systems. OS/78 provides
an extensive collection of application software development tools and
an efficient run-time environment for the production use of these
application programs.

OS/78 is controlled through a Consice Command Language (CCL)
that simplifies program development and execution (e.g., COPY
LOAD, HELP, etc.) The CCL allows the user to operate the system
through terminal commands.

The following three classes of functions are available through CCL:
System Functions, Language Functions, and Utility Functions.
