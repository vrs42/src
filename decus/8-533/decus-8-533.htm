"WHERE"
8-533

G. Chase, Portsmouth Abbey School, Portsmouth,
Rhode Island

Reads a binary tape and prints out the field and core areas
which that tape will occupy when loaded.

Minimum Hardware:
4K PDP-8/E with console, TTY,
Optional HSR
Other Programs Needed:
Binary Loader
Storage Requirement:
4400-4566 in any core field
Restrictions:
Will not run on 8/I or 8/L
Source Language:
PAL III

Catalog:July 1973
