XMARK
L-32
Author: Harold L. Pearson, West Virginia University, Morgantown, West Virginia
XMARK is a program which marks LINCtapes in a format which allows more efficient usage of the LINC-8 library System and the LEAP-1 System (DECUS No. L-15.1) tapes. It marks the tape in 128 word blocks with 1792 (3400 octal) blocks per tape. The standard tape marking program (MARKL8) marks 256 word blocks with 512 (1000 octal) blocks per tape. XMARK significantly increases tape capacity and speed of operation for PDP-8 programs on the LINC-8.
Other Programs Needed: DECUS No. L-15.1
Catalog: November 1969
