FILE: Text Data File Program for TSS/8 BASIC-4
BASIC8-47
Submitted by: David Dodell
Operating System: TSS/8
Abstract: This program creates a BASIC data file and allows the changing, inserting, and addition of numeric and alpha strings of data. A printout then can be made at either the beginning or end of the program.

Limitations: Will work only with TSS/8 BASIC that has disk and an optional DECtape. BASIC has to be of the type that has data file capabilities.
Size: 4 TSS/8 Disk Segments
Media Price Code: D2, G5
Catalog: August 1978
