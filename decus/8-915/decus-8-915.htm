PRINTR: A Text Utility for OS/8, Version: 3A and 4A, August 1981
8-915

Author: G. F. Forsythe, ARL, Melbourne, Australia

Submitted by: Stanley Rabinowitz and TECO Special Interest Group

Operating System: OS/8 Source Language: PAL-8/PAL-III Memory
Required: 8K Special Hardware Required: Version 3A requires Versatec
D800A; Version 4A requires a printer Other Software Required: OS/8
BASIC Keywords: Text Formatting

Abstract: PRINTR performs text output on an electrostatic plotter. This
allows additional features such as overstrikes, Greek characters, and
simple figures to be added to text files. The font may be modified during
use. CCL calls for this program, for RUNOFF and for a new
ZERO/LABLEL command have been provided.

Restrictions:
  • Reset causes problem for 1 scan; effects first line (if not blank) and line
    after control B.
  • Figure drawing addresses must be in monotonic order.
  • Line must not exceed 128 characters.

    Note: The following improvements have been made: CCL calls, font
    modification, version for normal printer, improved write-up.

    Documentation on magnetic media.

    Media Service Charge Code: Floppy Diskette (KA) Format: OS/8
    Catalog: June 1985
