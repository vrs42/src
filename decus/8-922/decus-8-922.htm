IKT-TUB FOCAL '81, Version: April 1981
8-922

Author: Klaus Lickteig, Technische Universitat Berlin, Germany

Operating System: OS/8 Source Language: PAL-8/PAL-III Memory
Required: Minimum 12K, Maximum 28K Special Hardware Required:
One or more of the following: AX08 A/D-Converter, KV8I Display,
KL8-JA Interface; AF04 A/D-Converter, DK8-EP Real time clock
Keywords: Utilities - OS/8

Abstract: IKT-TUB FOCAL '81 includes both PS/8 Focal '71 plus an
overlay which will control the handling of data files ("FX" function), the
AX08 A/D-Converter ("FLAB", "FADC(K)" functions), the AF04
A/D-Converter ("FADC(K,F,R,S)" function), the KV8I-display ("FD"
function), and the KL8-JA interface ("FIO" functions) and the DK8-EP
programmable real time clock ("FN(3,C)", "FN(4)" functions).

Some new functions "FN" are added. The old display function
"FDIS" is available too. The program will check the computer-hardware
and will modiify itself.

Ordering Information: No sources are available on tape, though the
listing is available in hard copy. The binary tape is complete.
