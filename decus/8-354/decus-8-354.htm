Pass 3 ASR33 Format Overlay
8-354

Frank Melchior, Jr., National Center for Atmospheric
Research, Boulder, Colorado

This overlay will automatically format the output from Pass 3
on the ASR33 teletype into page size blocks.

Minimum Hardware:
PDP-8, ASR33
Other Programs Needed:
PAL III (Digital-S-3L-5)
Storage Requirement:
33 locations
Restrictions:
High speed punch will NOT
work with this program
Miscellaneous:
Symbol table will have to be
punched on Pass 1
Source Language:
PAL III

Catalog: July 1973
