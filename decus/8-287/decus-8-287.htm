A PDP-8 Program to Provide Teletype Entry Into the IBM JET
8-287
System

E.G. Baxa, Jr., Duke University, Department of Electrical
Engineering, Durham, North Carolina

This program in effect uses the PDP-8 to simulate a teletype
machine which is equipped with X-OFF, X-ON, and EOT
features to accomplish entry into an IBM 360 computer with
the Job Entry Teletype {JET) interface. Minimal requirements
included as peripheral equipment to the basic PDP-8 are an
alternate teletype with FORTRAN keyboard and a standard
Dataphone Set. The program provides for teletype entry into
the Jet System from the keyboard or paper tape reader. A
teletype page print and/or tape punch record of the trans-
mission is obtained.

TUCC

GRAYCONV {Gray Code to Binary Code Converter)

Kees Bruin, Digital Equipment Corporation, The Hague,
Holland

GRAYCONV converts a binary word in gray code from l to
12 bits to an equivalent binary word.
