Three Subroutines for QANDA - FRACUS, SCRMBL, QANDA-C
12-25
Author: R. E. Kingsley, Indiana University, Bloomington, Indiana

FRACUS extracts decimal integer or fraction input from QANDA answer field and places floating point equivalent in user defined output field.

SCRMBL extracts octal or decimal integer input from QANDA answer fields and places the octal equivalent in user defined output field.

QANDA-C allows the decoding of the "CONTROL" character by QANDA.

Source Language: DIAL-MS
Catalog: July 1974
