The .pt files in this directory originate with Josh Dersch,
who imaged it for LCM+L.

I have stripped the parity bits to form the .pa files, 
added vrs-defines.pa to define various missing symbols.
There are also tweaks at the end of most of the .pa 
files, to add explicit PAGE directives, for compatibility
with the cross assember and similar assemblers.

The Makefile concatenates these various .pa files to 
create 8-341.pal, then assembles that to create the 
8-341.bin file.

The 8-341-LISP8-OBJECT-BINARY.pt file is apparently 
a dump of the memory from a loaded LISP8 image.  The 
generate .bin file has been verified to be equal to 
this image, except in locations where the source 
code does not specify contents.
