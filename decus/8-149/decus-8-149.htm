Core Window
8-149

Donald C. Uber, Lawrence Radiation Laboratory, University
of California, Livermore, California

The 34D Scope displays the octal contents of any 64 consecutive
core locations, beginning at the address set in the
Switch Register and Data Field switches (if Extended
Memory is used). There are 16 lines, each with an address
plus four memory words. A special character generator
program refreshes the display 11 times per second.

Minimum Hardware:
PDP-8, 34D Scope

Source Language:
MACRO-8

Storage Requirement:
15; 72408-75738

Catalog: November 1969
