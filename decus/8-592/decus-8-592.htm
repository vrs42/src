Printer Test Program
8-592

Derek J. Gardiner, Nortec Computer Devices, Southboro,
Massachusetts

This is a diagnostic program written for the lomec line printer
interfaced to the PDP 8/E. The printer is program compatible
with the DEC LE8 line printer but has expanded capability
with respect to paper format commands. The program ensures
the hardware is functioning as well as compatibility with LE8.

Minimum Hardware:
4K PDP-8/E, Line Printer - LE8 or
equivalent
Source Language:
MACRO-8

Catalog: July 1973
