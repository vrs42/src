2D Plotter for Serial Experimental Data
FOCAL8-84

Thomas J. Ford, White Mountains Regional High School,
Whitefield, New Hampshire

This program wil I accept and plot on TTY up to 40 sets of data
(in 4K). The printout is organized to display the Cartesian
Space by spacing through values of "Y" and line feeding
through values of "X" where these may represent any physical
quantities. Following the plotting of data, the display scale
factor and the adjusted values for the plotter parameter are
typed out by calling for the whole symbol table.

The program was designed to serve as a universal plotting
routine in its own right, but is group numbered to facilitate
incorporation into some other program as a dedicated display
routine.
