Tape to Memory Comparitor (6-channel)
8-291

T. D. Brenig-Jones, Digital Equipment Co., Ltd., Reading,
England

This program compares the contents of a 6-channel binary format
tape with those of core memory, and prints any differences
detected.

Minimum Hardware:
4K PDP-8, ASR33, High Speed
Reader
Storage Requirement:
l page, locations 7400 to 7577
Source Language:
PAL III

Catalog: July 1973
