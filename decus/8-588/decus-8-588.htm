PEEK, A User Program to Look at the TSS/8 Monitor
8-588

Paul Kinzelman, Carnegie-Mellon University, Pittsburgh,
Pennsylvania

PEEK is a diagnostic program for TSS-8 which enables a user
to look at any location or set of contiguous locations
(maximum of 8) in the resident monitor. The program is useful
to watch the monitor without disturbing the operation of the
monitor, PEEK may be run under any account number.

Minimum Hardware:
TSS/8
Restrictions:
Source tape has parity; should be run
through EDIT to remove parity
Source Language:
PAL-D

Catalog:July 1973
