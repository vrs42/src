RWTAPE
L-16
Author: Harold L. Pearson, West Virginia University, Morgantown, West Virginia
RWTAPE is a general input-output subroutine for LINCtapes. The program replaces the DECtape routines in the PDP-8 DECtape Programming System (DECUS No. 5/8-64). It will read or write consecutive blocks on any LINC-8 tape unit.
Storage Requirement: 1 page of memory
Catalog: November 1969
