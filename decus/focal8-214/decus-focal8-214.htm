FDSK, An Overlay for FOCAL to Read Data - Or Program Files
FOCAL8-214
from the PS/8 Systems Device

Hans Mees and Floor Anthoni, Medical Biological
Laboratory, T.N.O., Rijswijk, The Netherlands

FDSK provides 8K FOCAL with a minimum-core access to a
mass-storage device: the PS/8 system-device. It enables the
user to process data files (on the system-device) preprocessed
by other programs. It can be used to run FOCAL batch-wise.

As FOCAL was used to perform the last step in the processing
of data, only a READ on the system-device was implemented.
The data transfer is in ASCII format.

Minimum Hardware:
8K PDP-8; 64K Disk or DECtape
Other Programs Needed:
FOCAL '69 8K Overlay; PS/8
Programming System
Storage Requirement:
458 locations in Field 0; 6458
locations in Field 1
Source Language:
PAL-8, PAL III

Catalog:July 1973
