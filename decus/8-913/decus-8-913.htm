Abstract: TECO-8 is a fast, versatile character-oriented text editor.
Advanced features such as nested iteration loops, conditional execution
blocks and macro commands augment the many simpler editing
commands. TECO-8 will run on any PDP-8 or PDP-12 with at least 8K of
memory and the OS/8 operating system. Additional memory, up to 20K is
employed if available. This version of TECO runs at compatability level 1
as defined by the TECO SIG with the exception that Q-Register push
and pop are extended match control is not available. TECO-8 is upward
compatible with TEC's OS/8 TECO (V5) but is written in MACREL and
has a large number of additional features including support for FT-52's and
VT100's, super-TECO mode, read-with-no-wait, CTRL/C trapping,
type-ahead. War and Peace error messages, and support for TECO.INI
and TECO.TEC version 0 of a popular video editor written in TECO, and
TECKBM.TEC an OS/8 keyboard monitor emulator written in TECO.

Note: MACREL Assembler is required to generate a listing. 12K gives you
expanded buffers, 16K gives you extended error messages and resident
overlays, 20K gives you VT support. Documentation on the magnetic
media applies only to the PDP-8 version of TECO. For the complete
standard TECO manual order DECUS No. 11-450, Manual (EC).
