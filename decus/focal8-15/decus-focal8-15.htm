Least Squares Fit to a Cubic Polynomial
FOCAL8-15

Edward T. Chow, Georgia Institute of Technology, Atlanta,
Georgia

This is a program using the method of least squares to fit a
cubic polynomial to a set of experimental data. The program
demands two passes of the data for its completion; however,
the coefficients of the polynomial are outputted after the first
pass, and at the end of the second pass the output gives the
value of R which is a criterion of fitness and gives the calcu-
lated values of the experimental data based on the cubic
polynomial.

In addition, a section of the program can be used as a self-
contained program for solution of a set of N by N linear
equations.
