Fast Matrix Inversion for Real Numbers
FOCAL8-151

Richard Merrill, Digital Equipment Corporation, Maynard,
Massachusetts

This program will invert a matrix up to size 17x17 of real
numbers using modified Gauss-Jordan methods. It is translated
from DECUS NO. 8-72.

Minimum Hardware:
8K PDP-8, ASR33
Other Programs Needed:
FOCAL-11 or FOCAL-B with 8K
overlay
Restrictions:
If the error check is omitted,
sizable errors will occur
Source Language:
FOCAL-11 (DECUS NO. 11-24)

Catalog: July 1973
