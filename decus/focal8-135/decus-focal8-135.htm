MODV - Choice
FOCAL8-135

Arnold V. Fish, Digital Equipment Corporation, Parsippany,
New Jersey

This overlay provides a modified version of 8K FOCAL-69 in
terms of variable storage. It enables FOCAL to automatically
store variables in field 1 along with the text which is normally
stored there via 8K FOCAL. It gives the user more room in
field for user created functions. It provides for software pro-
tection of the last page of field 1 if desired.

Minimum Hardware:
8K PDP-8
Other Programs Needed:
FOCAL-69, 8K overlay
Source Language:
PAL-D and FOCAL-69

Catalog:July 1973
