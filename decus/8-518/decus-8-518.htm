PS/8 FORTRAN Alphabetical Sort
8-518

Edward Steinfeld
Submitted by: Karen Seefeldt, Digital Eguipment Corporation,
Pittsburgh, Pennsylvania

This is an alphabetical sort of any number of fields of any
width. The array to be sorted must be an integer array of
ASCII characters stored in A2 format. The program is a sub-
routine and is called from the main program.

Minimum Hardware:
PS/8 System
Other Programs Needed:
PS/8
Source Language:
PS/8 FORTRAN

Catalog:July 1973
