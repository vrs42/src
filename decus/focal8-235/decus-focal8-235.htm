MPS Radiation Pattern Program
FOCAL8-235

John G. Morey, Marvelwood School, Cornwall, Connecticut

The program will tabulate the radiation pattern shape (in
millivolts per meter at one mile) of any vertical element
directional antenna array. Extent of tabulation, number of
towers and operating values of each tower (based with reference
to one common point) are determined by user input.

Minimum Hardware:
4K PDP-8, ASR33, low speed reader
Restrictions:
Sine and cosine functions necessary.
Handles maximum of 10 towers
Source Language:
FOCAL 1969

Catalog:July 1973
