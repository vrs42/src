Symbolic Editor with View (338)
8-101

Barry Wessler

This program is an extended version of the standard PDP-8
Symbolic Editor (high-speed I/O) program. One extra
command has been added, "V", which takes the lines specified
by the arguments and displays them on the CRT (338). The
program, otherwise, operates in the same way as the Editor.
The following pushbutton options are provided:

0: Count Up Scale
1: Count Down Scale
2: Count Up Intensity
3: Count Down Intensity

Minimum Hardware:
8K PDP-8, 338 CRT, and VC-38
character generator.

Catalog: November 1969
