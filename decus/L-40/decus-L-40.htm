AVERAGER
L-40
Author: Dennis J. Nichols, University of Wisconsin, Madison, Wisconsin
The AVERAGER program provides a means of computing the average response of some signal-generating device to a series of excitations. Several options are available to the operator depending upon his specific needs.

The AVERAGER system provides a set of programs to average one channel while forming a post-stimulus histogram, average two channels, file data on tape, plot filed data, and measure latency and amplitude.

Source Language: LAP6
Catalog: November 1969
