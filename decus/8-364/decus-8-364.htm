Extended Memory Patch to the 3-Word Floating Point
8-364
Arithmetic Interpreter

Herbert Poppe, Lamont Geological Observatory of
Columbia University, Palisades, New York

This patch allows the 3-word Floating Point Arithmetic Interpreter
(DEC-08-YQYB) to reside in any memory field and to
be entered from that field or any other memory field.

Minimum Hardware:
PDP-8, extended memory,
memory extension control
Other Programs Needed:
DEC-08-YQYB
Restrictions:
Does not work with previous
version (DEC-08-YQYA)
Source Language:
PAL-D

Catalog: July 1973
