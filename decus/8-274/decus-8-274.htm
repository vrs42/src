Card Reader Patch to Phoenix Assembler
8-274

John Kiss, Algonquin College Technical Centre, Ottawa,
Ontario, Canada

This patch, if added to the Phoenix Assembler (DECUS NO.
5/8-28a), will enable the user to enter symbolic programs on
mark sense cards on the Hewlett-Packard 2761A Optical
Mark Reader.

Minimum Hardware:
Mark Sense Card Reader with
serial ASCII code output, PDP-8
with ASR33
Other Programs Needed:
Phoenix Assembler (DECUS NO.
5/8-28a)
Storage Requirement:
7402-7437
Source Language:
PAL III

Catalog:July 1973
