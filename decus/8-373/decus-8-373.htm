LISP Disk Array
8-373

Gary Coleman, Case-Western Reserve University, Cleveland,
Ohio

This program allows the user to store up to 4096 individual
numbers on disk. Storage is by a one-dimensional array. The
function is accessed by EXPR. Both the READ and WRITE
routines sit in the top of core, just under the monitor, and
occupy only 2610 locations (13 LISP cells). The function is
similar to FOCAL'S FNEW for disk.

Minimum Hardware:
PDP-8 with l DF32 Disk
Other Programs Needed:
LISP Interpreter for the PDP-8
(DECUS NO. 8-102a)
Source Language:
PAL-D

Catalog:July 1973
