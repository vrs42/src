Bibliographical Handling
8-416b

J. F. Echallier, A. laviron, F. Peronnet, P. Gerin,
I.N.S.E.R.M., lyon-Bron, France

This program makes it possible to store and to correct bibliographical
data, from ASR33 to DECtape. It allows printout
of references when given required characteristics. The program
should prove useful wherever a great deal of data is to
be stored, updated, and easily picked up.

Minimum Hardware:
4K PDP-8, ASR33, 2 DECtapes
Other Programs Needed:
Disk Monitor System (DEC-D8-SBAF)
Source language: PAL

Catalog:February 1972
