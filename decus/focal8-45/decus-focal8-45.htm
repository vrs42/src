Universal I/O Handler for FOCAL
FOCAL8-45

John C. Alderman, Jr., Applied Data Research, Atlanta,
Georgia

The Universal I/O Handler for FOCAL makes it possible to
write the hardware MAINDEC in a high-level language, and
with the possibility that maintenance people can change, or
write specific test routines in FOCAL as required.

Source Language:
FOCAL W
