Polynomial Least Squares Fit
8-549

Guy R. Sherwood, Edward Hines, Jr. V. A. Hospital,
Hines, Illinois

This program works on the least squares principle and calcu-
lates the coefficients for a polynomial equation. It allows
for up to 12 different degree equations. It also allows for up
to 12 values of X, F(X), and the weight of each value to be
entered. The program permits up to 3 values of F(X) for each
X to be entered. The maximum degree this program can fit
depends on the data.

Minimum Hardware:
8K PDP-8/I, TTY
Source Language:
PS/8 FORTRAN

Catalog:July 1973
