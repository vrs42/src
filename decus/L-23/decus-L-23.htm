Control to Designate Left or Right LINC-8 Tape Transport as Unit Zero
L-23
Author: R. W. Tuttle, K. Pavel, and C. F. Stroebel, Institute of Living Hospital, Hartford, Connecticut
Since many programs for the LINC-8 are designed to run only on Tape Unit 0, it has been found convenient to add a "NORMAL-REVERSE CONFIGURATION" switch to the LINCtape transports. This switch allows the operator to choose NORMAL (left-hand Unit 0, right-hand Unit 1) or REVERSE (right-hand Unit 0, left-hand Unit 1) designation for the tape transports. All tape control functions are shifted by this one switch. One could also place this switch under program control by either using the relay register or constructing a new one-bit register.
