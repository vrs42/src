Expanded Adding Machine
5-5

Donald V. Weaver, New York, New York

Expanded Adding Machine is a minimum-space version of
Expensive Adding Machine (DEC-5-43-D) using a table
look-up method including an error space facility.

This is a basic version to which additional control functions
can easily be added. Optional vertical or horizontal format,
optional storage of intermediate result without reentry fixed-
point output of results within reason, and other features that
can be had in little additional space under switch register
control. (Write-up and Listing Only)

Catalog: November 1969
