Hamming Algorithm to Solve Two Coupled Ordinary First Order
FOCAL8-217
Differential Equations with Given Initial Conditions

U. K. Shivadev, Harvard University, Cambridge,
Massachusetts

This program solves any two first order ordinary differential
equations simultaneously using Hamming's fourth order
algorithm.

Minimum Hardware:
8K PDP-8/E; Paper tape reader
Other Programs Needed:
DEC-08-LBAA-PM Binary Loader
and DECUS NO. FOCAL8-148
FOCL.S 8K
Source Language:
FOCL.S (DECUS NO. FOCAL8-
148)

Catalog: July 1973
