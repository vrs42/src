DECtape Library System Modifications
8-336

William Leal
Submitted by: Ernest Hayden, Speech Communications
Research Laboratory, Santa Barbara, California

The tapes and documents provided permit the PDP-8 user
running under the DEC-08-SUAl-LA DECtape Library System
to call in one program from another, and the, ability to write
programs which may be executed, and, when completed, leave
storage undisturbed, much like the system programs. These
programs are called phantom programs. Users running under
DIGITAL-S-7-S Rev 7/25/66 may make use of the phantom
features as is, but MODIND and OCTDMP will have to be
modified to accommodate the different directory format.

Minimum Hardware:
4K PDP-8, 1 TC01 DECtape Unit,
EAE
Other Programs Needed:
DEC-08-SUAl-LA or Digital-8-
7-S Rev. 7/25/66
Source Language:
PAL III

Catalog: July 1973
