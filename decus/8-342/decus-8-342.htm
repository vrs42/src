STAP-8; Spike Train Analysis Program
8-342

Urs R. Wyss
Submitted by: Charles Merrill, Digital Equipment
Corporation, Maynard, Massachusetts

STAP-8 is a subroutine package for basic statistical analysis of
stochastic point processes, written in PDP-8's PAL symbolic
assembler language and available as a machine language per-
forated tape in binary format. Main effort was not made on
sophisticated statistical techniques, but rather on a easy to
control, variable program library, including CRT-display,
paper tape output and teletype listings.

Minimum Hardware:
PDP-8/I with AX08
Other Programs Needed:
Floating point package DEC-S-25-
E/A
Storage Requirement:
4K
Source Language:
PAL III

Catalog: July 1973
