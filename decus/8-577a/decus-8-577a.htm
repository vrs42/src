Tape Duplicator (P.D.T.)
8-577a

Geoffrey Chase, O.S.B., Portsmouth Abbey School,
Portsmouth, Rhode Island

A simpler (modified) version of the Master Tape Duplicator
which does not use the interrupt facility. Buffered I/O
allows asynchronous copying.

Minimum Hardware:
PDP-8/E (F, M), HSR/P; can be
modified for low speed punch
Other Programs Needed:
Binary loader
Source Language:
PAL III

Catalog: July 1973
