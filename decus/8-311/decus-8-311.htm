Card to Tape Conversion with Diagnostics
8-311

B. J. Little, Sandia Corporation, Livermore, California

Converts cards punched in Hollerith code to paper tape
punched in ASCII code on either high or low speed punch.
I/O devices are operated at maximum speed. Character
validity and data loss checks are made on input cards. Error
diagnostics allow recovery from most conversion halts.

Minimum Hardware:
PDP-8/I, ASR33, CR-8/I
Storage Requirement:
Program: 0000-0600, Buffer: 0600-
7600
Source Language:
PAL III

Catalog: July 1973
