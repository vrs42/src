LOADBIN
12-27
Author: Dr. C. M. Malpus, University of Leeds, Leeds, England
LOADBIN is a utility program for use with the DATAFILE library system and is the means by wchich binary programs (as opposed to binary data) can be handled by DATAFILE. Binary programs written on LINCtape are filed on a DATAFILE tape by LOADBIN, which makes all necessary transfers, index updating and file sorting. Once programs are filed by LOADBIN, DATAFILE will retrieve and load them into absolute locations and start at any address.
NOTE FOR 12-26, 12-27, 12-28: The programs previously assigned these numbers were really LINC8 programs and were placed in this section of the catalog in error. See L-124A,B &C.
