BASIC8-64
Submitted by: Malcolm Slaney
Abstract: This is a simple program to punch out names and other messages on tape. Messages of any size that can be handled by the LINPUT command will be punched. It is also possible to specify whether the letter or the background should be punched. All alpha-numeric characters can be punched, and new characters, such as Christmas trees, are easy to add.
