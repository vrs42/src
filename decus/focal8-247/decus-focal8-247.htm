FNEWS Overlay to Use High Speed Punch with FOCAL
FOCAL8-247
Program

Alessandro Zanon, Istituto Nazionale di Fisica Nucleare,
Legnaro (Padova), Italy

This overlay adds three new functions to FOCAL-1969 and
modifies the scope routine. One of these functions may be
used to write a very short routine enabling the high speed
punch

Minimum Hardware:
4K PDP-8
Other Programs Needed:
FOCAL-1969 (DEC-08-AJAE-PB)
Source Language:
PAL-D

Catalog:July 1973
