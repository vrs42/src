NUFOCAL, Modified FOCAL-12
12-178
Author: William E. Hatcher, Veteran's Administration Center, Temple, Texas
This program is a patch to FOCAL-12 which allows the user to specify an output device which is unsuitable for output of an error message. A line printer not easily seen from the teletype might be such a device. If an error occurs when output is to the specified device, output will be restored to the teletype.
Minimum Hardware: 8K PDP-12
Other Programs Needed: DIAL Operating System
Source Language: PAL
Catalog: December 1974
