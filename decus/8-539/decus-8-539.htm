TD8E 4K Loader
8-539

Mark G. Roberts, Digital Equipment Corporcition,
Albuquerque, New Mexico

This package contains a one-page handler to load from TD8E
DECtape and a program to load paper tape onto DECtape. It
will load everything except last page of memory; requires
two passes of paper tape.

Minimum Hardware:
4K PDP-8/E, TD8E DECtapes
Other Programs Needed:
Binary Loader; TD8E DECtape
Subroutine
Restrictions:
Only works in 4K of memory
Source Language:
PAL III

Catalog:July 1973
