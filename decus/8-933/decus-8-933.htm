Moedling PASCAL-S, Version: V2.0, March 1983
8-933

Author: Niklaus Wirth, E.T.H, Zurich, Switzerland

Submitted by: D. Geoffrey Chase, OSB, Portsmouth Abbey School,
Portsmouth, RI

Operating System: OS/8 V3-D. Tested under V3-D, including ETOS and
OMNI-8, would probably run under other OS/8 versions. Source
Language: PAL-8/PAL III Memory Required: 28KW Keywords: PAS-
CAL; Structured Languages/Programming

Abstract: PASCAL-S is a subset of the programming language PASCAL,
defined by Niklaus Wirth in Report No. 12 of the Institute for Information
Science at the E.T.H. in Zurich. This implementation of PASCAL was
designed for the PDP-8 with 28K words of processor memory, running
under the OS/8 operating system.

Restrictions: (1) Uses BSW and MQL/MQA. See file PASCAL.8E. (2)
PASCAL-S is a subset of PASCAL. It conforms to definition of
PASCAL-S given by Niklaus Wirth, the original inventor of PASCAL.

Note: Source program text may be created or revised with any of the OS/8
File Editors, including MUTOR(1), EDIT and TECO.
