Patch to Add LABEL Feature to FOCAL 5/69 (DECUS NO.
FOCAL8-190
FOCAL8-52a)

Magnus Lundin
Submitted by: Lars Palmer, AB Hassle, Goteborg, Sweden

This patch adds LABEL (DECUS NO. 8-68a) in a slightly
modified version to FOCAL 5/69 in such a way that it can be
reached from keyboard by a new library command. The program
is stored in field 1, beginning at 7100 and can be removed
by another library command if all of field 1 is required for
large programs.

Other Programs Needed:
DECUS NOs. FOCAL8-52a and
FOCAL8-189
Source Language:
PAL

Catalog: July 1973
