Wilmot Grading Program
FOCAL8-161

William W. Wilmot, Central Michigan University, Mt.
Pleasant, Michigan

The purpose of this program is to average students' grades. It
can be used for any number of grades per student. It calcu-
lates the average grade for each student, the overall class
average, and the class standard deviation.

Minimum Hardware:
4K PDP-8
Restrictions:
Letter grades must be converted
to numbers
Source Language:
FOCAL-69

Catalog:July 1973
