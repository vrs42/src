EXIT PS/8
8-474

Edward Steinfeld
Submitted by: Karen Seefeldt, Digital Eguipment Corporation,
Pittsburgh, Pennsylvania

The EXIT program is used to exit from the PS/8 programming
system. EXIT will determine what the system device is and
load in the proper bootstrap. The program will also load a
binary loader into Field 1 and rewind all DECtapes.

Minimum Hardware:
PDP-8 DECtape, Disk
Other Programs Needed:
PS/8 software
Source Language:
PAL-8

Catalog:July 1973
