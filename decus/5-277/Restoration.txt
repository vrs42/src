This code was retyped from the listing by Devin Monnens. Subsequent
work was done to get it running on a PDP8/E (or SIMH) by Lars Brinkhoff
and Kyle Owen.

I was able to locate an executable (.SV) file in the archives of
Charles Lasner. The .SV file also has modifications to run on a
PDP-8 with VC8E.

In addition, the .SV file seems not to have a few of minor
transcription errors. I have edited a copy of the source to
match the "cjl" version, which is probably the recommended
version for newer machines.

I have also edited a version back to the "original" code, for
historical purposes.
