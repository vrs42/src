IRDA
12-4
Author: David Ferrarini, Digital Equipment Corporation, Maynard, Massachusetts
The IRDA (infra-red data acquisition) program acquires asynchronous data from an interfaced instrument, displays the data on the scope, and stores it on LINCtape. IRDA is compatible with any device that transmits X-Y data at a rate as fast as 103 milliseconds/point and'accepts up to a maximum of 1000(10) data points. The external asynchronous device is interfaced to the PDP-12 computer by two potentiometers, one transmits X axis input (independent variable), the other transmits Y axis input (dependent variable). For every one bit increment in the X axis, IRDA retrieves one value from the Y pot and stores it in the data area. For example, IRDA can generate an absorption spectrum from an infra-red spectrophotometer.
Minimum Hardware: PDP-12A with KW12A clock
Other Programs Needed: LAP6-DIAL
Source Language: FORTRAN
Catalog: July 1974
