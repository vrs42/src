OS/8; Utilities - OS/8

Abstract: This is a package of programs to aid in the cataloging and
management of the contents of large numbers of floppy disks, DECtapes,
LINCtapes and other media. The programs in this package are MEDIAI,
FIND, and MEDIAO. The following is a brief description of each:
MEDIAI reads the directories of the media. Each disk or tape is
identified by a volume number. A file containing information from the
directories and the associated volume numbers is created. Directories of
additional media and updates of existing directories may be placed in the
file from time to time.
FIND will do an on-line search of the file created by MEDIAI,
outputting information on each instance of selected files. Multiple files
may be selected in a single pass and wild card specifications may be used
in file names.
MEDIAO will create a formatted cross-reference directory sorted by
file name or by extension. A simple listing by filename and volume
number can be produced. A full listing with file length and date as well as
name and volume number is also available. SORT from the "WVU
Sort-Merge Utilitites" (available as DECUS No, 8-925) must be used to
order the master directory data before using MEDIAO.

Restrictions: This submission has not been tested under OS/78 V4,
however no problems are anticipated. This submission has not been tested
on the VT278 DECmate. There may be some terminal I/O incompatibility
that would require modification.
