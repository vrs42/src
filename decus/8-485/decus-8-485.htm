Geometric Data Truncation for Fourier Transform Programs
8-485

E. A. Barnhardt, Southwestern at Memphis, Memphis,
Tennessee

This program is intended for use as a truncating-weighting
subroutine. The application of a weighting function to the
data record before the application of a Fourier transform
program reduces the spread in frequencies which results from
the transformation of a finite record.
