BASIC8 Switch Register Function
BASIC8-88
Author: C. R. Desper, Army Materials and Mechanics Research Center Watertown, MA
Source Language: PAL-III
Memory Required: 8K
Other Software Required: BASIC-8
Abstract: This patch for the BASIC8 programming system permits input of numerical data through the switch register. Data is strobed in when switch zero is thrown up, then down. The subroutine is accessed through the UUF (X) function and the TAB function is dropped. The patch is used in the two-player version of the BASIC FOOTBALL game (BASIC8-85a).
