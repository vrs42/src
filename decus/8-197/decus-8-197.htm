Overlay for Standard Editor and PAL III Assembler
8-197

John Knox, International Controls Corporation, Houston,
Texas

This overlay enables the user of Editor (DEC-08-ESAB)
and PAL III Assembler (DEC-08-ASAC) to save approximately
half the time required when using the ASR-33/35. This
patch has proven to be a great time saver when debugging
was necessary.

Minimum Hardware:
PDP-8 with 8K
Other Programs Needed:
Editor (DEC-08-ESAB) and
PAL III (DEC-08-ASAC)

Catalog: November 1969
