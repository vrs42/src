FOCAL Display on a 338
FOCAL8-57

David Whitely, International Computers Limited, Kidsgrove,
Stoke-on-Trent, England

This program enables a vector display to be generated on a
338 using the instructions already available in FOCAL. It is
also possible to draw blank vectors and to erase the display
file under program control.

Minimum Hardware:
8K PDP-8, 338 Display
Source Language:
FOCAL

Catalog: July 1973
