Screening Regression
FOCAL8-76

Dr. Robert G. Miller, 30 Juniper Lane, Glastonbury,
Connecticut

This program performs a stepwise multiple linear regression
analysis. For a dependent variable Y the program selects or
screens from among a number of independent variables a subset
(7 or less) of the total number of variables which contains
most of the information of the entire set. There is no limit to
the number of independent variables used.

Minimum Hardware:
PDP-8/L, ASR33
Storage Requirement:
4096 words
Restrictions:
The cross product matrix is required
as input
Source Language:
FOCAL - 69
