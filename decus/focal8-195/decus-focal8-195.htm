All Purpose Graphing Program
FOCAL8-195

Mike Viola
Submitted by: Robert T. Cronin, Belmont Hill School,
Belmont, Massachusetts

This program can plot almost any type of eguation through the
three options afforded the user in the program. A11 graphs
are inverted and scaled down so that the entire graph fits on
the dimensions given the program. This makes selective
enlarging of any graph possible.

Minimum Hardware:
4K PDP-8, ASR33
Other Programs Needed:
FOCAL-QUAD
Storage Reguirement: At least 800 FOCAL locations
Source Language:
FOCAL '69

Catalog:July 1973
