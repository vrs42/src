Two Subroutines for 8K FORTRAN
8-480a
l. INPUT
2. RANDU and GAUSS

Lars Palmer, A. B. Hassle, Goteborg, Sweden

l. INPUT is o relocatable input routine for input in free
format to 8K FORTRAN programs.
2. RANDU and GAUSS are random number generators for 8K
FORTRAN.
