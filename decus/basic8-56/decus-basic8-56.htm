Laboratory and Display Instructions for OS/8 BASIC
BASIC8-56
Submitted by: Ronald Jones, Ph.D.
Operating System: OS/8
Source Language: PAL-8

Abstract: This program is a set of user-defined functions for OS/8 BASIC. It is combined with the LAB/8E
functions (DEC-8E-ALOSA-A-LA) to build the file BASIC.UF; a run-time overlay for OS/* BASIC. These
functions control DEC analog and Digital input and output devices and the VC8E display-control. They
permit real-time data sampling, with background display, and control of both the X and Y coordinates for
CRT plotting.
