HELP: A Disk/DECtape Dialogue Program
8-247

David P. Weaver, Georgia Institute of Technology,
Atlanta, Georgia

This program allows any message typed on the teleprinter to
be SAVED and printed upon calling HELP.

Minimum Hardware:
PDP-8, ASR-33
Storage Requirement:
11810 locations
Source Language:
PAL-D

Catalog:July 1973
