OCTYPE - Octal Memory Dump
8-755

Jeffrey A. Merrow, White Mountains Regional High School,
Whitefield, New Hampshire

OCTYPE's purpose is to output specified blocks of memory
as: The current location, followed by: data located there.
Input is from the teletype keyboard or low speed reader. The
program. will halt after each block is printed, but can be
recovered by pressing CONT.

Minimum Hardware:
4K PDP-8, ASR33
Source Language:
PAL III
Catalog:May 1975
