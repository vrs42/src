The source files decus-8-152.pal and decus-8-152a.pal were
retyped from the listings in decus-8-152-lst.pdf.  Additional
code from Kyle's 152a source was used to fill in the missing 
code from the truncated part of decus-8-152-lst.pdf.

Kyle's tape images were also used for the .bn binary images.

The Music.txt file explains the music file format, which is 
output by the "uncode" Perl scrip, and input by decus-8-152a.

The SIMH script "docode" patches 152a to output to the HSR,
and to accept 7-bit ASCII.  It then runs it under SIMH to
generate code.bin from the code.txt file.

The Makefile contains the rules build the rest of the files.

The .ms files here are as output by Perl, without mark parity.
Mark parity is required by the unpatched 152a.
 
The .bin versions have valid checksums -- it is unclear why 
the .bn originals did not.
