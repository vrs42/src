Author: R. A. Baragiola, N. Calwood and H. J. L Raiti, Comision
Nacional de Energia Atomica, Argentina

Operating System: OS/8 3Q (dsk fmt) Source Language: FORTRAN
IV, RALF Memory Required: 16KW Special Hardware Required: DEC
DR8 perallel interface. Houston Instruments HI PAD digitizer
Keywords: Digitizing Tablet Software; Houston Instruments

Abstract: This package contains the following programs:
HIPAD.RA, a RALF module to read the Houston Instruments' HI
PAD Digitizer using DEC's DR8 parallel interface.
POLGON.FT, a FORTRAN IV subroutine to calculate the
perimeter and area of a polygon defined by an array of vertices.
DEMO.FT, a FORTRAN IV program that uses the two previous
subroutines and allows the evaluation of perimeters and areas of arbitrary
figures defined by points entered with the digitizer, and using arbitrary
scale factors.

Documentation on magnetic media.
