First Order Differential Equation: Initial Value Problem
FOCAL8-182

Algorithm by Runge-Kutta
Submitted by: U. K. Shivadev, Harvard University,
Cambridge, Massachusetts

This program, which offers the 4th order Runge-Kutta method
of solving a first order non-linear differential equation, is
self-explanatory. Initial value, step size and termination
point are to be specified. Results are typed at specified
intervals.

Minimum Hardware:
8K PDP-8/E, ASR33
Source Language:
8K FOCAL '69

Catalog:July 1973
