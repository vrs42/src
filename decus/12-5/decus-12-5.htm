SERCHPRO
12-5
Author: Jean Champarnaud, Digital Equipment Corporation, Maynard, Massachusetts
Basically, this program does two things: 1. Tells the user the starting block number and the number of blocks of any binary file saved on a DIAL tape. 2. Indicates the starting mode (LINC or 8), starting address and actual memory locations into which the program will be loaded.
Source Language: LAP6-DIAL
Catalog: July 1974
