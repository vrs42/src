DSDPRINT, DDTYPE: Double Precision Signed Decimal
5,8-39
Input-Output Package

P. T. Brady, Department of Eiectricai Engineering, New
York University, New York City, New York

DSDPRINT, when given a signed 24-bit integer, types a
space or minus sign, and then a 7-digit decimal number in
the range -8388608 to t 8388607. DDTYPE enables a user
to type in a signed decimal number in either single or double
precision. These routines are already separately available,
but the present subroutine package occupies only one memory
page and allows for more efficient memory allocation.
Located in 3000-3177, but will work on any page.

Catalog: November 1969
