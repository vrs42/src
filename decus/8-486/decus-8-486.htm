SEGAR 7: A Seven Segment Array for Alphanumeric
8-486
Character Generation

David J. Dowsett, Atkinson Morley's Hospital!, Wimbledon,
England

This program is designed as a l 1/2 page (with pointers on page
0) subroutine for displaying easily observed labels on an
oscilloscope screen.

A seven segment display allows all numerical and some useful
alphabetical characters to be generated. Spacing is automatic
and can be altered.

Minimum Hardware:
PDP-8; 34 D Scope
Source Language:
PAL III

Catalog:July 1973
