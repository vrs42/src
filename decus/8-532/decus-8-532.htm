OPDDT (One Page DDT)
8-532

W. Friedman, Rockefeller University, New York, New York

This octal debugger may be run on any one page except zero.
Like OPT it is controlled from the teletype. It sets a breakpoint,
proceeds from one point to the next, examines and
changes memory.

Minimum Hardware:
4K PDP-8, TTY
Storage Requirement:
One page of core plus location
5
Restrictions:
Cannot run on page zero
Source Language:
MACRO-8

Catalog: July 1973
