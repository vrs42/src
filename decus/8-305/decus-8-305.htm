PAL III Assembler Overlay for Card Reader Input
8-305

B. J. Little, Sandia Corporation, Livermore, California

This overlay replaces high speed reader input with card reader
input. Character validity and data loss check is made on
input cards. Error diagnostics allow recovery from most read
and hardware error halts.

Minimum Hardware:
PDP-8/I, ASR-33, CR-8/I. High
Speed Punch optional
Other Programs Needed:
PAL III Assembler (DEC-08-ASBl
PB)
Restrictions:
Card input to be in Hollerith code
Source Language:
PAL III

Catalog:July 1973
