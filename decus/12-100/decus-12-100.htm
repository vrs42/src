MEMO III - A Text Formatting Program
12-100
Author: Mark F. Lewis, Federal Aviation Administration, Oklahoma City, Oklahoma
MEMO III is a program written for the OS/8 system to produce paged text with margins from free form text. The intention is to permit the user to produce readable and neatly formatted copy of text with in minimal effort.

MEMO III is a descendant of Gregory Ruth's original program. This version permits output on any OS/8 campatible output device, rather than restricting output to the teletype. Files written for MEMO nd MEMO II are compatible with MEMO III.

Minimum Hardware: PDP-8/12, ASR33 (or equivalent) and either DECtape or disk
Other Programs Needed: OS/8 Programming System
Miscellaneous: Same program is available on DECtape as DECUS NO. 8-427b
Source Language: PAL-8
Catalog: July 1974
