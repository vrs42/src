CalComp Plotting Package
8-168

John W. Fitzgerald, Stanford Medical School, Stanford
University, Stanford, California

This package is a series of subroutines designed to be used
with the CalComp and PDP-8. The subroutines are:

PLOTX -a modified 8-12-U, general move
routine
ALPHA -alphanumeric packed string plotting
DLTR -an 8-bit ASCII letter drawer
AXIS -an axis drawing routine
NUMBER -a signed 11-bit binary number output
routine
DSYM -centered symbol drawing routine
LINE -vector plotting routine.

This package is issued only on DECtape.

Minimum Hardware:
A PDP-8 computer with DECtape
350B interface and CalComp
Model 565 digital plotter with
a step size of 0.01 inches.

Catalog: November 1969
