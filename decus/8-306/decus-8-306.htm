LDR - A One Pass Transparent Loader
8-306

Douglas Henry, Physics-Astronomy Department, Vanderbilt
University, Nashville, Tennessee

LDR replaces standard Disk Monitor loader but never requires
a second pass and is completely transparent. It is in two files:
LDR, which is called by the user to start the load and .LDR,
which does most of the work.

Minimum Hardware:
4K PDP-8, DF32, Teletype
Other Programs Needed:
Disk Monitor head must be in core
Restrictions:
Requires blocks 367-375 for scratch
Source Language:
PAL-D

Catalog:July 1973
