Card III Overlay
8-229

Roger L. Bachand, MITRE Corporation, Bedford, Massachusetts

This program makes PAL III available for input from the card
reader option (CR8/I) for reading IBM-026 source cards. The
user punches on each card one PAL III line of text using the
same symbol and operation as in compiling on ASCII source
tape. Operation is the same as PAL III.

Minimum Hardware:
4K PDP-8, ASR-33, CR8/I card
reader

Other Programs Needed:
PAL III

Source Language:
PAL-III

Catalog: July 1973
