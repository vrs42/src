Fixed Point Trace No. 2
8-57

B. J. Biavati, Columbia University, New York, New York

Similar to Fixed Point Trace No. 1 (DECUS No. 8-56) except
that the symbolic tape provided has a single origin setting
instruction of 6000. Any four consecutive memory pages
can be used, with the exception of page zero, by changing
this one instruction.

Catalog:November 1969
