Memory Compare
8-182

Ray H. Jones, Digital Equipment Company, Ltd., Reading,
England

Memory Compare resides in page 368 of either field. It
compares contents of similar addresses in pages 0-358 of
both fields and outputs any differences detected.

Minimum Hardware:
PDP-8 with extended memory

Source Language:
PAL-D

Storage Requirement:
1 page

Catalog:November 1969
