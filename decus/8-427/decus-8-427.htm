MEMO - A Text Formatting Program
8-427

Gregory Ruth, MIT, Charles Stark Draper Laboratory,
Cambridge, Massachusetts

MEMO transforms free-form text into paged right-and-Ieft-
justified output suitable for documentation. The input file
(of text) must be produced by EDIT or have identical appear-
ance.

Minimum Hardware:
PDP-8, ASR33, DECtape or Disk
Other Programs Needed:
PS/8 System
Storage Requirement:
Locations 0-3377
Source Language:
PAL 8

Catalog:February 1972
