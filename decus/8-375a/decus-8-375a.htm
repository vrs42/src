Three Page Floating Point Package
8-375A

Richard Rothman, Digital Equipment Corporation, Maynard,
Massachusetts

This package makes available an alternative to the lengthy
floating point package distributed by DEC and also utilizes
the concept of cutting down exponent size to allow a larger
mantissa. It uses 3 word numbers, with 27 bit mantissa and
8 bit exponent.

Minimum Hardware:
4K PDP-8
Storage Requirement:
Locations 50-64, 5410-6177
Source Language:
PAL 10, Version 141

Catalog:July 1973
