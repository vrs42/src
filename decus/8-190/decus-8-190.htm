PATCH Utility Program
8-190

James A. McDonough, Concord Control, Boston,
Massachusetts

This program, a utility routine, allows duplicating and up-
dating of a DECtape file of any PDP-8 TC01 format. It is
derived from a combination of ODT (DEC-08-COBO-D) and
XDUP (DECUS No. 5/8-64). The user should be familiar
with the operation of both of these programs.

Minimum Hardware:
PDP-8 with TC01 Control

Catalog: November 1969
