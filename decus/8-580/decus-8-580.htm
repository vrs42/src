Decimal to Floating Point Conversion
8-580

R. Jacot, Integra A. G., Wallisellen, Switzerland

If a lot of data in floating point format are required, this
program can be used to generate a complete source tape of
the data in floating point format after they have been typed
in decimal form. The generated tape can be assembled
independent of the main program.

Minimum Hardware:
4K PDP-8, TTY
Other Programs Needed:
Floating Point Package 1 or 2
(DEC-08-YQ1B-PB or DEC-08-
YQ2B) 4/17/70
Restrictions:
Runs only on low speed punch
Source Language:
PAL III

Catalog:July 1973
