FORTRAN Source Conversion Program
8-170

Charles Conley
Submitted by: Richard Palmer, Digital Equipment Corporation,
Maynard, Massachusetts

This program will allow the user to convert FORTRAN source
programs written for DEC-08-AFC1 (FORTRAN Compiler,
Old Version) to the new format, FORTRAN (DEC-08-AFC1-
PB).

Catalog: November 1969
