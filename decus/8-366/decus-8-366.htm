Modified Readable Punch
8-366

Andres T. Siy, Capitol Institute of Technology, Kensington,
Maryland

This program is similar in many respects to DECUS NOs. 8-
68a and 8-106. It allows the user to type any characters
whose ASCII code is 240 to 337, and produ1ce an 8 X 6
matrix readable outline of the character on tape. The added
features are: (a) new 6 words per character tags, and (b)
there are provisions for output devices selection.

Minimum Hardware:
4K PDP-8, ASR33, HSP
Storage Requirement:
Locations 20-43; 200-310
(SA=200); and 400-1177 for Tags
Source Language:
PAL III

Catalog:July 1973
