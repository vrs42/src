ORGAN-AA and ORGAN+BA
12-86
Author: Andres J. Magre, COASIN S. A., Buenos Aires, Argentina
Program to allow use of the PDP-12 to simulate organ music. Two versions are supplied. One allows the user to play directly from the keyboard. The second is similar, but the notes are first stored in core and retrieved consecutively each time any key is struck.
Minimum Hardware: PDP-12, 4K core
Storage Requirement: Approximately one 8-mode page Variable from there
Source Language: PAL III
Catalog: July 1974
