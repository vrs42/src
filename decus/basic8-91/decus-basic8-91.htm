BASIC8 Single Key Reader
BASIC8-91
Author: Jeffrey Shrager, Radnor High School
Operating System: OS/8
Source Language: PAL-8
Other Software Required: OS/8 BASIC
Abstract: It is often convenient to be able to read a single keystroke in the process of a BASIC program. Normal input is done via the INPUT statement, but this method requires that the user type a return at the end of input. KEYIN permits the program to poll the terminal for keystrikes and read and process these keys without having to stop the program and wait for input.
Restrictions: BRTS User Overlay Area
