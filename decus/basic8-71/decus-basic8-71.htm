CALC
BASIC8-71
Submitted by: Jesse Heines
Operating System: OS/8
Source Language: BASIC
Abstract: CALC allows you to input any valid BASIC numerical expression and prints out the value of that expression on a CLASSIC or OS/8 system.

This program uses one BASIC language program to write another, CHAINs to a newly written program, and then CHAINs back to the original one.
