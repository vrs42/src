UNIDEC Assembler
8-123

C. Stephen Carr, University of Utah, Salt Lake City, Utah

The UNIDEC Assembler runs on the Univac 1108 and passes
assembled PDP-8 code over the electronic link between the
1108 and PDP-8. The source statements are punched on
cards for input into the 1108 in a format nearly identical to
that of MACRO-8. A printed Iisting and object code are
produced as fast as the cards can be read.

Note: Source deck and documentation only available.

Catalog:November 1969
