FX Function for Random Access Files
FOCAL8-268

Lawrence Moss, Cardiopulmonary Lab., University of
Vermont, Burlington, Vermont

The function FX is a random access data function for use with
PS/8 FOCAL. It allows the user to build and handle data
files in a random fashion, rather than in the sequential pattern
which is standard with PS/8 FOCAL. The maximum array size
is 2047 floating point variables, of either six or ten digit
precision.

Minimum Hardware:
8K PDP-8 or PDP-12 with mass
storage device
Other Programs Needed:
PS/8-12 or OS/8-12, OMSI
PS/8 FOCAL (DECUS NO.
FOCAL8-177)
Source Language:
PAL-8
