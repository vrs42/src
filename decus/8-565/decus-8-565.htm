RENUM - Renumbering Program for BASIC Tapes
8-565

Dom Geoffrey Chase, O.S.B., Portsmouth Abbey School,
Portsmouth, Rhode Island

Designed to resequence an Edu-20 BASIC tape so that all line
numbers are multiples of (decimal) 10. The first line number
in the new version is line 100. Commands which reference
line numbers (THEN, GOTO, GOSUB) are readdressed to
conform to the new numbering.

Minimum Hardware:
8K PDP-8E, F or M, ASR33 or
PT8E high speed reader/punch
Source Language:
PAL III

Catalog:July 1973
