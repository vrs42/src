Core Editor
8-276

Anthony Bolton, Scribner Hill Road, Wilton, Connecticut

This program enables the user to debug his program in core
and then get a binary write-out of the program by a simple
command. The user can also write a program directly into
core by using the insert command which increments the loca-
tion referenced by typing a space. It has six other commands.

Minimum Hardware:
4K PDP-8, ASR33
Source Language:
PAL III

Catalog: July 1973
