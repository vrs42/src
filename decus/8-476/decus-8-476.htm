PS/8 LOG Command
8-476

For users who previously ordered this program the following

patches are suggested.

To eliminate LOGON feature: During system generation, ofter
loading the modified PS/8 tape and CONFIG, change location
00271 from 4052 to 7000 using ODT.

On DECtape based system: The LOGON, OFF, and KJOB
commands use location 07777 for a flag to indicate LOG ON
or OFF status.

For CONFIG with DECtape system handler at 07777 change
the line reading "SBLKCT=7777" to "SBLKCT=7753." This
assumes that the disk that would use location 7753 for data
break is not present in a configuration where DECtape is the
system device.
