Patch to Allow Computed Line Numbers in FOCAL, 1969
FOCAL8-254

Eben F. Ostby, RR#l, Box 10, Hampton, Connecticut

This patch loads over the routine XGETLN in FOCAL,
modifies that routine to allow for computed line numbers,
returns the correct value for LINENO with evaluatable
arguments. In addition it still allows the use of the argument
ALL.

Minimum Hardware:
PDP-8
Restrictions:
Disables ADC function; not usable
with 8K and 4 word overlays.
Argument for evaluatable line
numbers must not start with letter
"A"
Source Language:
PAL

Catalog: July 1973
