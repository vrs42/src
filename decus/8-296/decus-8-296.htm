Edit Routine
8-296

J. Russell Lemon, United States Air Force, Rome Air
Development Center, Rome, New York

This is a minimum length (slightly over 3 pages) edit routine
capable of editing, reading into, reading out of and jumping
to any core location. It accepts only valid inputs (octal
only). Program input can be either ASCII, binary or RIM.
Output can be ASCII, binary or RIM tape. The program can
edit itself and is a useful tool for programming in machine
language.

Minimum Hardware:
PDP-8 and Teletype
Storage Requirement:
6760-7577
Source Language:
Machine Language

Catalog: July 1973
