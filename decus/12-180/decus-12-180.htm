CARDDIAL - Input to the DIAL Editor Via Cards
12-180
Author: James C. Good, Jamesville-DeWitt Central Schools, DeWitt, New York
CARDDIAL is a program which makes card input acceptable to the DIAL editor.
Minimum Hardware: PDP-12, Card Reader, LINCtape
Other Programs Needed: PAL-12A Assembler
Storage Requirement: 0000-0777
Restrictions: Same as for the DIAL Editor
Source Language: PAL-12A
Catalog: May 1975
