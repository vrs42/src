SPEAKR.BAS: A Vented-Box Speaker Enclosure Calculator, Version: October 1982
8-931

Author: Jeff Reyer

Operating System: OS/8 Source Language: BASIC Memory Required:
4KW
Keywords: Engineering Applications

Abstract: The SPEAKR program allows you to designa vented (ie.
ported) box speaker enclosure (ie. Hifi speaker) provided you know three
parameters about the driver:
  • Qts (total driver Q factor)
  • Fs (driver resonant frequency)
  • Vas (compliance equivalent volume)

    It calculates te volume of the box (Vb), the diameter of the port
    (Dv), the length of the port (Lv), the peak or sag in the cabinet response
    (R), the -3dB cutoff frequency of the box (F3), and the resonant frequency
    of the enclosure (Fb). All measurements are in International Units:
    volume in liters, length in centimeters, and response in dB.

    Restrictions: Originally written for VT100, (ANSI mode) but user may
    patch one line in sources for either VT52 or hardcopy mode.

    Note: This program uses Keele's approximation method.
