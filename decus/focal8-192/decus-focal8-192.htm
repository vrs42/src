Echo Change for FOCAL, 1969
FOCAL8-192

G. Chase, Portsmouth Abbey School, Portsmouth, Rhode
Island

This is a patch for one-user FOCAL, 4K or 8K, to allow
killing (and restoration) of echo by typing an asterisk(*)
followed by a carriage return. The High Speed Reader
routine in FOCAL is sacrificed when this patch is used. No
user or function storage is taken .

Catalog:July 1973
