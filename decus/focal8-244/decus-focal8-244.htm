HANGMAN IV
FOCAL8-244

Andrew Layman, Stamford High School, Stamford,
Connecticut

This program will allow user to play Hangman with only 4K.
It is virtually idiot-proof and simulates non-computer game
in playing style almost perfectly.

Minimum Hardware:
4K PDP-8, ASR33
Other Programs Needed:
FOCAL 5/69 (DECUS NO.
FOCAL8-52a)
Restrictions:
Delete Functions
Source Language:
FOCAL 5/69

Catalog:July 1973
