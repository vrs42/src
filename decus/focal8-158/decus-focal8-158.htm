Mileage Program
FOCAL8-158

Corl Kishline, University of Wisconsin, Kenosha, Wisconsin

Computes the overage gas mileage from the fuel consumption
and distance, after which it will estimate the cost of fuel for
a trip of a given length.

Minimum Hardware:
4K PDP-8, ASR33
Miscel loneous: This program will operate on a 7-
user FOCAL system and should work
on any FOCAL system including 4K
with the extended functions

Catalog: July 1973
