8-901
Author: J. P. J. Maurissen & A. Vanderheide
University of Rochester, Rochester, NY
Operating System: OS/8, OS/12
Source Language: FORTRAN IV
Memory Required: about 1600 12-bit words
Other Software Required: DEC#QF014

Abstract: This program is a routine based on DEC's version of AXIS.FS. It has been developed on a
PDP-12 computer. This subroutine has one new argument which allows use of full logarithmic or reverse
logarithmic cycles. Labeling of tic marks has been changed so that on both X and Y axes, labels are written
a a 0 degree angle.
Restrictions: Cannot be used in conjunction with PSCALE for logarithmic plots.
