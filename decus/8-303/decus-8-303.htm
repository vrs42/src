Alterations of the Basic Floating-Point Package and
8-303
Additional Subroutines

W. Roos, Philips Research Laboratories, Eindhoven,
Nether lands

Using the basic floating-point package DEC-08-YQlB, or the
other existing versions, this package can only be called from
instruction - and data field zero. For a PDP-8/I with extended
memory it becomes necessary for additional subroutines
to overcome this drawback.

Restrictions:
Data and instruction fields must be
the same. Addresses of additional
subroutines must be locations 5, 6
and 7 of page zero
Source Language:
PAL

Catalog:July 1973
