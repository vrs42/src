INPUT, OS/8 Version
8-571

Lars Palmer, Ph.D., AB Hassle, Molndal 1, Sweden

This is INPUT (DECUS NO. 8-480a) rewritten to function
better under OS/8. All OS/8 devices can be read. This
version will not function with paper tape FORTRAN II. A data
file can be constructed with EDIT and read by FORTRAN.

Minimum Hardware:
OS/8 Configuration
Other Programs Needed:
8K FORTRAN
Source Language:
SABR

Catalog: July 1973
