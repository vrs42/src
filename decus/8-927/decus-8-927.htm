SPLT55: Data Display/Plotting System for BASIC/LAB 55, Version: March 1980
8-927

Author: G. F. Forsyth, Aero Research Labs, Melbourne, Australia

Operating System: OS/8 V3D Source Language: BASIC Memory Re-
quired: 8K Special Hardware Required: VT55 and/or Printer/Plotter
(VERSATEC or LV8) Keywords: Graphics

Abstract: SPLT55 is a data entering, editing, displaying and plotting
system written in BASIC/LAB55; that is, in OS/8 BASIC with the added
features od DECUS 8-885. It allows any two of eight graphs to be
displayed on a VT55 graphic terminal, and allows all eight on an
electrostatic (LV8) plotter.

Documentation on magnetic media.
