The image I found on bitsavers is decus-5-9.bad.
It has a problem where one of the data words on 
the 0600 page is missing either it's high or low 
half.

The file decus-5-9.err "fixes" this by adding a 
"044" before "007", forming a call to the floating 
point package, and aligning the data thereafter 
to look like instructions.  The result still has 
a sizeable checksum error, so there are still 
additional errors.

Fortunately, I was able to obtain another copy 
from eBay, which does not report a checksum error, 
and have added that as decus-5,8-9.bn.

I have retained the stuff from bitsavers, since
it appears to be rather different from the eBay
version.

The file foo.{pal,lst,bin} is a disassembly of 
decus-5,8-9.bn.
