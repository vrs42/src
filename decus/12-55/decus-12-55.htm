FFAESIM
12-55
Author: H. G. Helgeson, Forsvarets Forskningsanstalt, Stockholm, Sweden
This program makes it possible to runthe FFTD program on a PDP-12 without the EAE option. It consists of a modified version of Digital-8-17-U, Extended Arithmetic Element Instruction Set Simulator, and a patch to change the EAE instructions in FFTD.
Minimum Hardware: 8K PDP-12B
Other Programs Needed: FFTD (DEC-12-FQEA)
Storage Requirement: 165-177; 200-357; 1600-1653
Source Language: LAP6-DIAL
Catalog: July 1974
