Using the RAR RAL Micro-Instruction as an Auxiliary Command
8-788
Author: J. S. B. Clark, Poultry Research Centre, Edinburgh, Scotland
The limited instruction set of the PDP-8/L can cause program inefficiency. A modification is described which allows the redundant micro-instruction RAR RAL to be used as a control command. An example of its use in enabling another modified command under program control is given.
Hardware Required: PDP-8/L or PDP-8/I (unverified)
Source Language: PAL III, PAL-D
Restrictions: Involves a hardware modification
Catalog: June 1976
