PLOTTY: A Program to Plot a Function On a Teletype
BASIC8-84
Submitted by: Jorge Paloschi, Argentina
Source Language: 8K BASIC
Abstract: This program plots through a teletype any one variable function, printing the axis if they are within the plotting domain.

It allows the user to choose the graph scale and also to apply a function to the ordinates (as to get semilogarithmic graphs, for example).

The program was designed to minimize the graph printing time.
