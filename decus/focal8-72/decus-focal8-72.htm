General Least Squares Fit
FOCAL8-72

Harold Metcalf, SUNY Stony Brook, Stony Brook, New York

Can be used to fit data to any arbitrary curve (line, expo-
nential, polynomial, Gaussian, Lorentzian, etc.). Curve is
specified by the calculation in group 3, so any curve that can
be calculated can be fitted to data.

Minimum Hardware:
8K PDP-8
Source Language:
FOCAL

Catalog: July 1973
