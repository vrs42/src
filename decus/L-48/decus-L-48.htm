DECBIN: Decimal-to-Binary Conversion
L-48
Author: Dennis J. Nichols, University of Wisconsin, Madison, Wisconsin
The DECBIN subroutines convert decimal keyboard codes stored in memory to binary integers. Four routines are supplied: DECBIN 1, DECBIN 2, DECBIN 3, and DECBIN 4.
Source Language: LAP6
Catalog: November 1969
