Solution of Linear Equation Systems with Symmetrically Matrix
FOCAL8-242

K. Wagner, Technische Universitat Berlin, Berlin, Germany

The program gives the solution-vector, an approximate error-
vector and the condition number of a linear equation system
with symmetrically matrix.

8K PDP-8E
Other Programs Needed:
