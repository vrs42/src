BIN Punch for Extended Memory
8-310

Rainer Schongar, Siemens, Munich, Germany

This program is useful for simple loading of tested FORTRAN
programs via the Binary Loader. The field instructions for the
Binary Loader are automatically generated by this program.
In one field the Binary punch for extended memory shares the
core memory with the Binary loader.

Source Language:
PAL

Catalog:July 1973
