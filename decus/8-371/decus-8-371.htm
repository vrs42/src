Teletype Control of ND 50/50 Memory Unit (TYPED)
8-371

W. J. Blanchard, Louisiana State University, Baton Rouge,
Louisiana

TYPED is a program to allow the user quick access to Nuclear
Data's 50/50 Memory and Display unit via the ASR33 teletype.
After entry through the monitor, the user types in the starting
channel (l-4096) and the program echoes the contents which
are then subject to modification. The program contains two
control characters, one in case of error made in typing channel
contents, the other is a terminal character which returns
control to the monitor routine.

50/50 interface system
