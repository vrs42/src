XOD Modification for use with FOCAL
FOCAL8-2

Georgia Institute of Technology
Submitted by: John Alderman, Applied Data Research,
Atlanta, Georgia

This program contains modifications to XOD (DECUS NO.
8-89) which allow it to be used to debug FOCAL. It also
contains certain changes for the command character set
which make them more like ODT-2, which is desirable for
installations with many inexperienced users.

Catalog: July 1973
