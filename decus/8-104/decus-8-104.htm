Card Reader Subroutine for the PDP-8 FORTRAN Compiler
8-104

Steven Sullivan, Oregon State University, Corvallis,
Oregon

Modifications and additions which allow the PDP-8 FORTRAN
Compiler to read source programs from cards. The standard
FORTRAN card format is used with only minor modifications.

Minimum Hardware:
8K PDP-8 and a Type CR01-C
Card Reader

Catalog:November 1969
