CORDMP - Formatted Octal Dump
8-448

Arthur L. Pike, Tufts University, Medford, Massachusetts

This program punches an octal core dump into tape for off-
line listing. The dump arranges the contents of 8 core loca-
tions on a line, with the starting address at the left, and with
column headers for easy reading. Markers are provided for
cutting the listings into 11-inch lengths. The accumulator
lights display each address being punched.

Minimum Hardware:
4K PDP-8/I, ASR33, HSP
Storage Requirement:
One page page-relocatable in any
field
Restrictions:
Dumps only one field or portion
at a time
Source Language:
PAL-8/PAL III

Catalog:February 1972
