FOCAL "WRITE" Patch
FOCAL8-51

John Larkin, Technical Associates, Inc., Metairie,
Louisianna

This patch changes the FOCAL "WRITE" routine to add blanks
to paper tape generated by "WRITE," which corrects the
"INPUT BUFFER OVERFLOW" error generated by loading long
paper tapes into FOCAL-69

Other Programs Needed:
FOCAL-69
Restrictions:
Will not run with 8K FOCAL

Catalog: July 1973
