Octal Character Equivalent
8-616

David Dodell and Michael Wax, Dix Hills, New York

This program will find the 8-bit ASCII code equivalent for
any letter or symbol typed, with the exception of CTRL C.
It will run only under the TSS/8 monitor, but can be easily
converted for a stand-alone PDP-8.

Minimum Hardware:
TSS/8
Source Language:
PAL-D

Catalog:July 1974
