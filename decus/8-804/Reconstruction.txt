This directory has been reconstructed from the contents of
ftp.dbit.com/pub/pdp8/nickel/music.  The file names and
author information match closely, so hopefully this is the
same stuff that was in the DECUS package.

One file that is missing is medley.bi, a batch control file.
I have substituted a one block file full of text indicating
that the file contents have been lost.

Another was playov.pa.  The playov.pa here is from 
ftp://ftp.update.uu.se/pub/pdp8/pdp-8/music/wilson
A number of the .mu files are slightly different as well.

The nickel archives store PDP-8 data 2 bytes per word, so the
files here have been packed 3 bytes per doubleword, as my tools
expect.
