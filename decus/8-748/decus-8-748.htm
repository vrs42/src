SM04 - OS/8 to Disk—Monitor ASCII File Converter
8-748

Gerald A. Sabin, 6022 Sage Drive, Orlando, Florida

SM04 will be found useful by regular users of DEC's Disk
Monitor. It is a utility program that will convert an ASCII
file on an OS/8 DECtape reel into an ASCII File on Disk-
Monitor DECtape. User needs to know the absolute block
numbers of his input OS/8 ASCII File. SM04 will output,
via Disk-Monitor, into a file named by the user.

SM04 is written in FORTRAN—D and uses a number of FOR-
TRAN tricks that have appeared in DECUSCOPE over the
last few years to accomplish the required machine language
subroutines.

Minimum Hardware:
4K PDP-8, 2 DECtape transports,
TTY
Other Programs Needed:
Disk—Monitor System
Source Language:
FORTRAN-D
Catalog: May 1975
