This is the all memory clear portion of 5,8-27.

The file clear.{pal,lst,bin} contains an 
annotated disassembly of the code.

The file willard.{pal,lst,bin} includes the bug fix described
by Willard Crittenden in the 1967 DECUScope Volume 6, Number 6.

junk.{pal,lst,bin} is used in pdp8.ini to fill memory with JMP
instructions to set up a test whether the program has worked
correctly.
