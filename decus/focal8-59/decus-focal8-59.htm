FOCAL Overlay Common Area for 4K Core Memory
FOCAL8-59

Herbert Zimmermann, Digital Equipment GmbH, Koln,
Germany

This program is an overlay which implements the common area
with the function FNEW. Two versions of the overlay tape
are available, one for FOCAL without extended functions,
and one for FOCAL with extended functions. The overlay
"common area" is read in in a normal way.

Minimum Hardware:
4K PDP-8
Other Programs Needed:
Binary loader; FOCAL
(DEC-08-AJAE-PB)
Source Language:
FOCAL

Catalog: July 1973
