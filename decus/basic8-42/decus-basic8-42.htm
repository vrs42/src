RECOVE: BASIC RECOVERY FROM CRASHBASIC8-42
Submitted by: James Puccio
Abstract: This program will allow the TSS/8 BASIC programmer to recover from system crashes and user-induced halts of BASIC. If the user is on a system that has two versions of BASIC, one simple BASIC and one extended BASIC, the program also allows selection of which processor to link to.
