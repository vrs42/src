PDP-12 User's Monitor Command
12-122
Author: Mark J. Hyde, Jamesville-DeWitt Central Schools, DeWitt, New York
This is an implementation of the DIAL user's monitor command functions as an extension of the 4K LAP6-DIAL-V2 system. It provides the user of such a System with a convenient way to zero the working area of any tape unit, merge binary files, and respecify the assembler permanent symtol tables.
Minimum Hardware: Same as 4K DIAL
Other Programs Needed: LAP6-DIAL
Source Language: LAP6-DIAL
Catalog: July 1974
