DISORT
8-562

John Alderman, Digital Communications Associates, Inc.,
Atlanta, Georgia

This is a program to produce alphabetically ordered directory
listings for PS/8. With minor patches it can be used to sort
any ASCII file under PS/8.

Minimum Hardware:
PS/8 Configuration
Other Programs Needed:
PS/8 or OS/8 Operating System
Source Language:
PAL-8

Catalog:July 1973
