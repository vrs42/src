EAE Overlay for Four-Word Floating Point Package Multiply
8-575

Gregory Ruth, M. I. T. Charles Stark Draper Laboratory,
Cambridge, Massachusetts

This overlay allows the Four-Word Floating Point Package
(DEC-08-FMHA-D) to use an EAE in multiplication, thus
decreasing the time to interpret an FMPY by a factor of 5.

Minimum Hardware:
PDP-8, EAE
Other Programs Needed:
DEC-08-FMHA-D
Source Language:
PAL-8

Catalog: July 1973
