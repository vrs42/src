MPS External Event Common Routines
8-699

Thomas McLeod, Digital Equipment Corporation, Maynard,
Massachusetts

The Microprocessor Series offers a priority vectored external
event module which allows the accessing of up to eight soft-
ware routines. This software package contains two common
routines which would be entered by all of the above eight
routines. The first would be entered and 5 of 7 registers and
status codes saved in Random access memory (RAM). A user
routine would then be entered and processing accomplished.
The final routine would be the Restore routine.

Restrictions:
Registers D & E are used For
temporary storage
