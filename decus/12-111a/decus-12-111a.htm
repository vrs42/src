ADFILE, a modification of ADTAPE to run under PS/8 on a PDP-12A, is a data acquisition program that permits from one to sixteen AD12 A/D channels to be sampled consecutively.
Minimum Hardware: 8K PDP-12A with KW12A, AD12, (RF08 disk optional)
Other Programs Needed: PS/8 Operating System
Restrictions: Must be run on a PDP-12A with LINCtapes or RF08 disk as output device; PS/8 or OS/8 must be built with CONFIG -- not BUILD
Source Language: PAL-8
Catalog: July 1974
