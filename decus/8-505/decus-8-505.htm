BIN-CBL Extended Memory Loader
8-505

Jan J. Mader, Brandeis University, Waltham, Massachusetts

This loader maintains all features of DECUS NO. 8-338
(automatic selection of either BIN or CBL format, etc.). In
addition it recognizes the field designation characters on
binary or CBL tape so that it allows one to load a program to
any memory field.

Minimum Hardware:
4K PDP-8/E, TTY
Storage Reguirement: One memory page (200 octal
locations)
Restrictions:
Low speed I/O devices only.
PDP-8/E only
Source Language:
PAL III

Catalog:July 1973
