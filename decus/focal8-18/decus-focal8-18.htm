T-ASK
FOCAL8-18

J. Alderman, Applied Data Research, Atlanta, Georgia

This subroutine, available in two versions, Standard FOCAL
Version and FNEW Array FOCAL Version, allows the user to
enter an input unit, as well as a number, and converts the
number to a common unit before returning to the calling
program. It is particularly useful for programs utilizing
TIME as an input parameter, since the program wil I convert
the following units to seconds: YEARS, DAYS, HOURS,
MINUTES, SECONDS, AND FORTNIGHT.

Catalog: July 1973
