SWAP - FOCAL Disk Data Overlay
FOCAL8-110a

James J. Chang, University of California at Berkeley,
Chemistry Department, Berkeley, California

This overlay causes the 8K FOCAL interpreter to use the last
two tracks of a DF32 disk for the storage of variables. The
number of variables which may be used in an 8K system is
changed from over 100 to well over 600 variables. Program
execution time is, however, severely increased.

Minimum Hardware:
8K PDP-8/I, DF32 disk
Other Programs Needed:
FOCAL, 1969 (DEC-08-AJAE-PB)
and utility overlays (DEC-08-
AJ1E-PR)
Restrictions:
Only works with this version of
FOCAL and overlay
Source Language:
PAL, MACRO

Catalog: July 1973
