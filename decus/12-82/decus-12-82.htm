LAP6-DIAL TO PS/8 SOURCE FILE CONVERTER
12-82
Author: Mario DeNobili
Submitted by: Stanley Rabinowitz, Digital Equipment Corporation, Maynard, Massachusetts
This program allows you to convert source files stored on LAP6-DIAL LINCtapes (400 words per block) to any PS/8 file. It runs under PS/8.
Minimum Hardware: PDP-12, PS/8 configuration
Other Programs Needed: PS/8 system
Source Language: PAL-8
Catalog: July 1974
