Miniloader and Miniloader Punch
8-268

G. J. Flanagan, The University of Newcastle Upon Tyne,
Newcastle Upon Tyne, England

This is a program which is designed to be loaded as easily as
possible from the switch register. Once loaded, the program
is capable of loading and starting any other program punched
in the correct form, though because of the lack of any check-
ing facility it would normally load a standard binary loader.
The miniloader format is such that, if the program is to be
loaded at the high-numbered end of the field, the length of
the tape is just over half the length of the same program
punched in RIM format.

Source Language:
PAL

Catalog:July 1973
