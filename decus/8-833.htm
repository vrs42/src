VT50 CURSOR MOVE
8-833
Author: Jeffrey Shrager
Radnor High School, Newton Square, PA
Operating System: OS/8
Source Language: PAL-8
Other Software Required: OS/8 BASIC

Abstract: Direct BASIC cursor control of the VT5O line of CRT can
entail a rather complex BASIC subroutine. CMOVE enables the programmer
to pass the vertical and horizontal coordinates to a BASIC/8
user function which will move the cursor to that position and stop.
