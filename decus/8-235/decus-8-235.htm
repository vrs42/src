Octal Tape Dump for PDP-8/9/10 DECtapes
8-235

Frank J. Nagy, Carnegie-Mellon University, Pittsburgh,
Pennsylvania

This program allows the user to dump blocks of PDP-8/9/10
DECtapes as octal numbers. The user is asked for the device
(DECtape and unit or disk) and the block number. The block
is read in and printed as l2, l8 or 36 bit numbers in octal.

Minimum Hardware:
PDP-8 with TC01 DECtape
control (DF-32 Disk optional)

Other Programs Needed:
Disk/DECtape Monitor System
(DEC-D8-ASAA)

Catalog:July 1973
