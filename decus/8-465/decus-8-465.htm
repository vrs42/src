SKED is a process control software system that has been de-
veloped for use in the behavioral research laboratory. The
software system consists of:
A. The Two-Pass SKED Compiler
B. The Run Time System (R. T. S.)
C. The DEBUG System
D. The System Builder

Minimum Hardware:
4K PDP-8, ASR33, real-time
100 cycle clock, hardware
interface between processor and
the experimental stations. High
speed reader and punch and
extra 4K useful and desireable
