PING-PONGBASIC8-74
Submitted by: Edward J. Quigley
Operating System: EDU-20
Source Language: BASIC
Special Hardware Required: 8K - 3 user PDP-8/L, any terminal
Abstract: This program allows you to play Ping-Pong against the computer, in a manner similar to that of game room machines. Properly hit balls are returned by the computer. Play continues until the program beats the opponent in a 7-0 shutout.
Media Price Code: D1
Catalog: August 1978
