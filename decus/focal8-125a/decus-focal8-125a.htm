Magtape Formatter for MTA Handler
FOCAL8-125a

John Alderman, Applied Data Research, Atlanta, Georgia

This creates the formatted magtape required for use with
DECUS No. 8-391, MTA Handler for PS-8. The program is
started by a 'GO' and the tape length is entered by the
operator. A formatted tape is then created, complete with
zeroed directory, ready for use with the handler.

Minimum Hardware:
8K PS-8 System configuration,
TC-58/TU-20 (7 track) IBM
Compatible tape unit
