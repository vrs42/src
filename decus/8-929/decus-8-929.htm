Random-Letter Generator, Version: March 1982
8-929

Author: Stephen A. Kallis, Jr.

Operating System: Independent Source Language: FOCAL Memory
Required: 4KW Keywords: Utilities - OS/8

Abstract: This is a short program to output groupings of letters selected
randomly using the FRAN() function of a subroutine using the function.
Letter groups are structured in groups of four, but this can be modified
easily. Letter groupings can be used for a variety of purposes, including
development of additive cyphers in cryptology or examination of patterns
generated by the pseudo-random number generator.
