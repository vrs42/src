MACRO-8 Pass 3 Output Format Patch
8-519

Richard J. LaBelle, Airborne Instruments Laboratory,
Deer Park, New York

This patch will format the Pass 3 output on the teletype into
page size blocks of either single sheets or fanfold paper.

Minimum Hardware:
4K PDP-8
Other Programs Needed:
MACRO-8 (DEC-08-CMAB-
PB)
Restrictions:
Reduces zero page literal buffer
by approximately 25%
Source Language:
Machine Language

Catalog: July 1973
