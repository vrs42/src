OS/8 VAX Handler, Version: B, August 1980
8-921

Author: Jim van Zee, Laboratory Data Systems, Seattle, WA

Operating System: OS/8 (Works on VAX Version 1 only), OS/78, DS/8,
PS/8, OS/12 Source Language: PAL8 Special Hardware Required: Serial
line communications interface Keywords: Device Handlers

Abstract: The VAX handler allows any PDP-8 or PDP-12 to send files to
(or receive files from) a VAX computer. No special programs are required
to do this: the handler may be used with any OS/8 program and presumes
only the existence of the $COPY command on the VAX. Only ASCII data
may be transferred, but commands as well as data may be sent to the
VAX, hence an OS/8 program can use this hander to do 'parallel
processing" on data collected by the '8 or '12.

Restrictions: OS/8 FORTRAN IV programs using this handler for input
can only put output files on the system device.
