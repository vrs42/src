INCMOD: Increment Mode Compiler (338)
8-108

Michael S. Wolfberg, Moore School of Electrical Engineering,
University of Pennsylvania, Philadelphia, Pennsylvania

The INCMOD program for the DEC 338 Display allows the
user to build a display subroutine composed of increments
only. The user inputs information by pointing with the
light pen. The program displays the figure he is constructing
in each of the four available scale settings. The program

is of value as a demonstration and may be of help for
maintenance purposes. It occupies locations 00000-01231
and builds the increment mode display file beginning at
location 01232.

Storage Requirement:
0000-12318

Minimum Hardware:
PDP-8 with 338 Display

Catalog:November 1969
