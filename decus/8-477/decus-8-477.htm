RIBIER - A Program for the PDP-8/I Enabling the Transition
8-477
from the PS/8 System to the Paper Tape System

Rene P. Loreton, University of Essex, Colchester, Esses,
England

Loads the RIM and BIN loaders in the original position in both
fields by first calling them in a lower core region and execution
of a relocation program. Afterwards, the memory locations
up to 7477 are cleared and control is given to the binary
loader with IF=l, DF=0.

Minimum Hardware:
8K PDP-8, One DECtape transport
Storage Requirement:
7600-7777 and 17600-17777
(like PS/8 monitor)
Source Language:
PAL-8

Catalog: July 1973
