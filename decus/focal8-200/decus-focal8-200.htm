SIMEQR - 20 Simultaneous Equations in 8K FOCAL
FOCAL8-200

Arthur L. Pike, Tufts University, Medford, Massachusetts

This program provides solutions of as many as 20 linear
simultaneous algebraic equations with real-number coeffi-
cients. The program also tabulates the input data with row-
column labels for efficient verification.
