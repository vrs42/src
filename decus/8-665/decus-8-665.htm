INTVAL - A Subroutine to Measure Inter-Event Intervals
8-665

A. J. Swan, Agricultural Research Council's Poultry Research
Centre, Edinburgh, Scotland

This subroutine may be called to measure the time interval
between events with a specified degree of accuracy. Inter-
vals are stored as non-zero, single precision, unsigned inte-
gers. This is an efficient way to code activity information
since histograms can easily be generated to allow examina-
tion of the activity later.

Minimum Hardware:
Any Lab 8 configuration
Storage Requirement:
3 locations on page zero and
1078 locations on any other page
Restrictions:
All device flags must be cleared
before call
Source Language:
PAL III
