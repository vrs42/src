FORTRAN Subroutines for the PDP-12
12-75
Author: Thomas V. McCaffrey, Loyola University Medical Center, Maywood, Illinois
This package consists of eight subroutines and functions written for real time control of the PDP-12's clock display, A to D's sense switches, external line levels, relays and left switches.

The ASCII tape offered with the package is a sample FORTRAN pragram for a time interval histogram which demonstrates the subroutines.

Minimum Hardware: 8K PDP-12
Other Programs Needed: 8K FORTRAN System or PS/8 System
Source Language: FORTRAN, SABR
Catalog: July 1974
