FLHSTO
FOCAL8-130

R. W. Carter, St. Peter's College, Jersey City, New Jersey

FLHSTO is a focal program which first provides a "tight" loop
which gathers and counts data values while storing only unique
entries. A frequency table and display follow second, and a
histogram follows third and last. If storage permits, these
sections may be used as subroutines.

Minimum Hardware:
4K PDP-8
Source Language:
FOCAL-69

Catalog: July 1973
