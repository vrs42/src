TS8REV - Reverse Assembler for TSS/8
8-543

William Harts, Dix Hills, New York

This program is an adaptation of DECUS NO. 8-178, Reverse
Assembler, which has been modified to run on a standard
TSS/8 computer. It will provide PAL mnemonics from any
RIM, BINARY or SAVE format tape. This can be very useful
in debugging a program when the user does not have a
symbolic listing.

Minimum Hardware:
TSS/8
Storage Requirement:
15 TSS/8 Disk Segments
Restrictions:
HSR input and TTY output only
Miscellaneous:
Tape offered is TSS/8 SAVE format
Source Language:
PAL-D

Catalog:July 1973
