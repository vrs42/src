Page Printer
8-356

G. Kermez and W. Peters, Texas Instruments Limited,
Bedford, England

This program is designed to produce pages of a required length
from ASCII paper tape fed from either the low speed or high
speed readers.

Minimum Hardware:
4K PDP-8/L, ASR33
Restrictions:
Tape to be read must be set at
first character
Miscellaneous:
Set switch register to l to run
program

Catalog:July 1973
