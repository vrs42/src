Editor-with-View (VD 8/I or 34D Scope)
8-209

John C. Alderman, Georgia Institute of Technology, Atlanta,
Georgia

Editor-With-View is the same as the library distributed version
of the Disk Editor (DEC-D8-ESAB) with the exception of the
V(View} command addition. This command is exactly like the
L command for the TTY, except that results are displayed on
a storage scope via the software character generator, and
the VD8/I or 34D scope controller. The ALT MODE key
will display the next line of the text buffer.

Minimum Hardware:
8K PD P-8 with VD.8/I or 34D
Scope
Catalog: November 1969
