ESIX - Extended ESI
8-504B

Robert Supnik, Applied Data Research, Cambridge,
Massachusetts

ESIX is an extended and improved version of ESI which runs on
any 8K or larger family computer. It offers all the features of
regular ESI, plus the following additional features: five times
more program and array storage, automatic pagination of
output, built in extended functions (SIN, COS, EXP, SQRT,
LOG, LN, ARCTAN), generalized exponentiation, compound
statements and comment statements.

Minimum Hardware:
8K PDP-8
Source Language:
MACRO-8X

Catalog:July 1973
