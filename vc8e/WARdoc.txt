/ There are two I/O devices implemented on the space war board:
/    A VC8E, at IOT address 05.
/    A parallel input port, implemented on port 14.
/
/ The parallel input port is the simplest.  8 bits are implemented, 
/ four at each end of the AC.  The voltage levels at the appropriate 
/ pins of J2 will be driven into the AC during a 6144 instruction.
/ Other 614x IOTs will behave as in the M1703.
/
/ The VC8E portion of the board implements DILC, DICD, DISD, DILX, 
/ DILY, DIXY, and DILE instructions compatible with the DEC VC8E.
/
/ Some features of the VC8E were not documented.  In particular, 
/ bits 1-9 of the Enable/Status register are described as "not 
/ used".  These bits in fact control various pins at connector J1:
/ Bit	Function
/ 1-5	Really are unused
/ 6	Write_thru, useful with storage 'scopes.
/ 7	Store, useful with storage 'scopes.
/ 8	Erase, useful with storage 'scopes.
/ 9	Color (1 == red)
/
/ Bits 6-9 are stored in the Enable/Status register.  Bits, 6, 7, 
/ and 9 will be read when reading status.  Leaving them zero gives
/ non-store behavior on storage 'scopes like the VT01/TEK611.
/
